## 📌 Executive Summary

**ORACLE** is an autonomous, multi-agent AI trading system built for the **Alpaca AI Trading Agents Hackathon**. 

Traditional algorithmic trading bots rely on rigid rules or a single LLM prompt, making them vulnerable to blind spots and market regime shifts. ORACLE introduces a novel **Contrarian Council** architecture — an internal investment committee where **5 specialized AI agents** (Bull, Bear, Risk, Quant, and Judge) engage in multi-perspective debate before any order is sent to the market.

Once approved by the Council, ORACLE constructs and executes complex **multi-leg options strategies (Iron Condors)** via Alpaca's Trading API, while automatically broadcasting plain-English trade rationales.

### Agent Roles:
- **🟢 Bull Agent**: Argues upside momentum, growth catalysts, and bullish technical setups.
- **🔴 Bear Agent**: Challenges with macroeconomic headwinds, downside traps, and bearish catalysts.
- **🟡 Risk Agent**: Enforces strict portfolio risk parameters, position sizing, and tail-risk bounds.
- **🔵 Quant Agent**: Analyzes statistical edge, Implied Volatility Rank (IVR), and delta/gamma exposure.
- **⚖️ Judge Agent**: Synthesizes all arguments, assigns a confidence score (0–100), and issues the binding decision.

---

## ✨ Key Features

- **🎯 Volatility & Momentum Scanners**: Scans live intraday data for extreme price moves (>5%) and calculates historical VIX market regimes (`CALM_BULL`, `VOLATILE_BEAR`, `EXTREME_FEAR`).
- **🦅 Automated Multi-Leg Options**: Dynamically constructs 4-leg Iron Condor options orders using Alpaca's `mleg` API class with strike selection based on underlying price.
- **🛡️ Embedded Risk Gates**: Hard drawdown circuit breaker (5% max daily loss limit) and single-trade position sizing cap (2% max capital risk).
- **📢 AutoNarrator**: Automatically converts multi-agent debate decisions into transparent social media updates.
- **🖥️ Dual Interfaces**: Includes both a fast CLI test harness (`demo.py`) and a full interactive Web Dashboard (`app.py`).

## 🚀 Quick Start

### 1. Prerequisites
- Python 3.12+
- Alpaca Paper Trading Account ([API Keys](https://alpaca.markets))
- Groq or OpenAI-compatible API Key

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/swatiicfai/ORACLE-Omniscient-Reasoning-and-Capital-Allocation-with-Live-Execution.git
cd ORACLE-Omniscient-Reasoning-and-Capital-Allocation-with-Live-Execution

# Create virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .\.venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### 3. Environment Configuration
Copy `.env.example` to `.env` and fill in your keys:
```bash
cp .env.example .env
```

```ini
# Alpaca Paper Trading
ALPACA_API_KEY=your_alpaca_paper_key
ALPACA_SECRET_KEY=your_alpaca_paper_secret
ALPACA_BASE_URL=https://paper-api.alpaca.markets

# AI Engine (Groq / OpenAI)
FEATHERLESS_API_KEY=gsk_your_groq_api_key
FEATHERLESS_MODEL=qwen/qwen3.8-27b
FEATHERLESS_BASE_URL=https://api.groq.com/openai/v1
```

### 4. Run the Hackathon Demo
```bash
# Run CLI Demo Sequence
python -u demo.py

# OR Launch Web Dashboard UI
streamlit run app.py
```

On Windows, you can also simply double-click `run_demo.bat`.
